1. 안티그래비티 호출어 세팅 규칙
--------------------------------------------------------------------------------
프롬프트:
"지금부터 내가 무조코야 라고 부르면, 너는 MuJoCo로 시뮬레이터를 만들어줘. world.xml과 run.py로 만들어서 창으로 띄워줘."

안티그래비티의 역할:
1) world.xml: MuJoCo 3D 물리 모델(MJCF 형식) 생성
2) run.py: 실시간 물리 연산 및 3D 뷰어 렌더링 코드 작성
3) 3D 인터랙티브 창 즉시 실행


2. 8강 단계별 마법의 프롬프트 모음
--------------------------------------------------------------------------------
[1단계: 농구공 튕기기]
"무조코야 시멘트 바닥에 농구공 튕기는 시뮬레이터 만들어줘"
"농구공에 물리 적용" (FIBA 7호 공인구 0.62kg, 반발계수 0.82 감쇠 바운스)

[2단계: 강철구 & 1,000톤 극한 물리]
"농구공을 철공으로 변경해줘" (지름 20cm 강철 밀도 32.8kg)
"야 철공이라고 하기에는 너무 풍선 같애. 이 공을 1,000톤으로 바꿔!" (1,000,000kg 무반발 쿵 낙하)

[3단계: 공 에이전트 자율주행 환경]
"무조코야 공 모양의 인공지능 에이전트가 목표를 향해 굴러가는 시뮬레이터 만들어줘"
"현재 공의 무게는?" (5kg -> 너무 가벼워서 튕김)
"최고 속도는 몇 km/h야?" (45km/h -> 너무 빠름)
"무게 100kg로 늘려줘" (100kg 티타늄 구체로 묵직한 조향 제어)

[4단계: 강화학습 환경 전환 (보상과 처벌)]
"이걸 강화학습 환경으로 바꿔줘.
보상: 목적지에 도착하면 10점
처벌: 밖으로 날아가면 -5점
Gymnasium 형식으로 만들어."

[5단계: PPO 학습 시작]
"이 환경을 PPO를 사용해서 학습 시작." (성공률 13% -> 16.5% -> 20.0% 상승)

[6단계: Gymnasium 공식 환경 등록]
"이거 gymnasium name 뭐라구 어떻게 불러오면 될까?"
-> 공식 등록 이름: BallNav-v0
-> 파이썬 호출:
   import gymnasium as gym
   import ball_nav_env
   env = gym.make('BallNav-v0', render_mode='human')


3. 3D 뷰어 조작 가이드
--------------------------------------------------------------------------------
- 마우스 좌클릭 + 드래그: 카메라 360도 3D 회전
- 마우스 우클릭 + 드래그: 카메라 평행 이동 (Pan)
- 마우스 휠: 화면 줌인 / 줌아웃
- Space (스페이스바): 일시 정지 / 재생
- 공 더블클릭 + Ctrl + 우클릭 드래그: 마우스로 공을 직접 집어서 던지기
- R 키: 시뮬레이션 처음 위치로 리셋
